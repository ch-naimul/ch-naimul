## Featured Work

**🧠 Brain Tumor MRI Classification — Ablation Study**
Systematic comparison of 5 architectures (EfficientNet-B0 → hybrid CNN–Swin Transformer) on 4-class MRI classification, with statistical significance testing (Wilcoxon) and quantitative explainability evaluation. Max test AUC: 0.9998.
`PyTorch` `Grad-CAM++` `Attention Rollout` `Statistical Testing`

**🩺 Diabetes/Resilience Prediction from Health Indicators**
Gradient Boosting pipeline on 250k+ records, with SMOTE for class imbalance and GridSearchCV tuning. 85% accuracy, 0.944 AUC-ROC.
`Python` `Scikit-learn` `SMOTE`

**🔍 Unsupervised Tile Surface Defect Detection**
Convolutional autoencoder trained only on defect-free images (MVTec AD benchmark), using a combined MSE+SSIM objective and leakage-free evaluation protocol. 91% precision, 0.78 F1.
`PyTorch` `OpenCV` `Autoencoders`
